朝食・昼食・夕食・間食のデータがすべて消去されます。よろしいですか？

STEP1：食材カテゴリ（種類で決まる）

🟢 A食材：野菜全般・果物・皮なし鶏肉・白身魚介・きのこ・海藻・豆腐・調味料少量・プロテイン単体 → 量に関係なく常に0
🟡 グッドB：1人前120〜200kcal未満（納豆・バナナ・オートミール・さつまいも・全粒粉パン等）
🔴 B食材：1人前200kcal以上（白米・パン・麺類・揚げ物・スイーツ・油大さじ2等）

STEP2：量によるカウント

A食材 → 常に 0
グッドB → 少量0 / 1人前（120〜200kcal）0.5 / 200kcal超 1
B食材 → 少量0 / 半人前0.5 / 1人前1 / 大盛り2

📌 納豆の例（グッドB）

1パック（70kcal）→ 0 ／ 2パック（140kcal）→ 0.5 ／ 3パック（210kcal）→ 1

🍗 揚げ物（食材を分解してカウント）

①主食材：本来の分類で判定　②衣：少量→常に0　③吸収油：カロリーで判定
鶏もも肉唐揚げ（皮付き）= もも肉B1 ＋ 吸油0.5 ＝ B1.5
鶏むね肉唐揚げ（皮なし）= むね肉A0 ＋ 吸油0.5 ＝ B0.5
フライドチキン（皮付き・厚衣）= もも肉B1 ＋ 吸油B1 ＝ B2
野菜天ぷら 2〜3個 = 野菜A0 ＋ 吸油0.5 ＝ B0.5
